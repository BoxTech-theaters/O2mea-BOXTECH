Questions designers and owners ask

How many pages are published?

Whatever lights up as a link on this map. The count changes when a deep page is added, not when a title is added.

Is the map for the visitor or the editor?

Both. The visitor sees the limit. The editor sees the debt.

Where is the glossary?

A separate page. The first batch is working terms, not 300 empty definitions.

Is there a page per city?

No, and they will not be cloned.

How does phase 2 get added?

When the page is written to the same structure: definition, limit, question, source.
